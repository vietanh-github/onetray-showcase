# OneTray

![OneTray](https://linva.net/onetray/images/onetray-hero-b14.webp)

**An all-in-one menu bar toolkit for macOS (Apple Silicon).**
15 tools in one tiny native app: under 20 MB RAM, everything runs 100% on-device.

Website and download: https://linva.net/onetray

## Why OneTray

Buying the equivalent tools separately costs about $247.97/year in subscriptions plus $123.96 in one-time purchases, and roughly 1.2 GB of RAM. OneTray replaces them in a single 6.1 MB app.

## The 15 tools

9 tools free forever · 6 Pro tools with a 7-day trial

1. Screen recording with Auto-Zoom (Pro)
2. Screenshot, scrolling capture and OCR (Pro)
3. Video Studio: convert, compress, trim, GIF (Pro)
4. Image optimization and metadata removal (Pro)
5. AI background removal (Pro export)
6. Disk cleaner and treemap (Pro cleanup)
7. PDF Studio: merge and split free; compress, password, watermark, OCR (Pro)
8. Image converter (free up to 3 images per batch)
9. Clipboard manager (10 items free, 100 Pro)
10. Four-edge drop tray and ZIP stash
11. External display brightness via DDC/CI
12. Window management: 16 shortcuts, edge snap
13. Finder cut and paste with Cmd+X / Cmd+V
14. Network speed, battery, running apps, force quit
15. Menu bar utilities: Keep Awake, color picker, QR codes, quick notes
